# План реализации локальной библиотеки (Скачивание + Транскодирование + Совместный просмотр)

## Суть фичи
Пользователь может выбрать торрент (фильм или конкретную серию сериала) и нажать «Скачать на сервер». Сервер скачивает видеофайл, затем транскодирует его в HLS (разбивает на `.ts` сегменты для идеальной перемотки) и сохраняет в локальную библиотеку. 
Доступ к библиотеке осуществляется через новый раздел в меню Лампы. Воспроизведение идет по статичному HLS-плейлисту, что обеспечивает мгновенную перемотку, отсутствие буферизации и 100% совместимость с **Sync Player** (совместным просмотром).

---

## Архитектура решения

### 1. Хранилище (File System)
В `docker-compose.yml` добавим новый volume для библиотеки:
- `data/library/raw/` — временная папка для скачивающихся сырых файлов (mp4, mkv).
- `data/library/hls/` — папка для готовых HLS-сегментов и плейлистов (после транскодирования сырой файл удаляется).

### 2. База данных (Drift SQLite)
Создаем таблицу `LibraryItems`:
- `id` (String, UUID)
- `tmdbId` (Int)
- `type` (String: 'movie' | 'tv')
- `season` (Int, nullable)
- `episode` (Int, nullable)
- `title` (String)
- `magnetUri` (String)
- `status` (String: 'pending' | 'downloading' | 'transcoding' | 'ready' | 'error')
- `progress` (Real: 0.0 - 100.0)
- `errorMessage` (String, nullable)
- `createdAt` (DateTime)

### 3. Бэкенд (Dart Frog)
**Сервисы:**
1. **`DownloadService`**: 
   - Принимает magnet-ссылку.
   - Обращается к TorrServer (через его API `/stream` или `/torrent/add`), чтобы выкачать файл на диск в `data/library/raw/`.
   - Периодически обновляет `progress` в БД (статус `downloading`).
2. **`LibraryTranscodingService`**:
   - Берет скачанный файл из `raw/`.
   - Запускает `ffmpeg` для генерации статического VOD HLS плейлиста (`playlist.m3u8` и `segment_*.ts`) в папку `hls/`.
   - Обновляет `progress` в БД (статус `transcoding`).
   - По завершении удаляет сырой файл и ставит статус `ready`.

**API Эндпоинты:**
- `POST /api/library/add` — добавить торрент в очередь загрузки.
- `GET /api/library/list` — получить список всех загрузок и их статусы (для UI).
- `DELETE /api/library/remove/:id` — удалить фильм с диска и из БД.
- `GET /api/library/play/:id/[...path]` — отдача `playlist.m3u8` и `.ts` сегментов.

### 4. Фронтенд (Lampa Plugin - `local_library.js`)
- **Кнопка скачивания:** Встраивается в окно выбора торрентов (там, где кнопки "Играть", "Трейлер").
- **Раздел меню:** В главном меню слева появляется пункт "Моя библиотека" (или "Загрузки").
- **UI Библиотеки:** Сетка карточек с фильмами. На карточках отображается статус: "Скачивание 45%", "Конвертация 12%" или кнопка "Смотреть", если статус `ready`.
- **Плеер:** При клике на "Смотреть" плагин передает URL `https://[host]/api/library/play/[id]/playlist.m3u8` во встроенный плеер Лампы.

---

## Совместимость с Sync Player (Совместный просмотр)
Так как итоговый файл отдается сервером как обычный статический HLS-плейлист по HTTP, Sync Player будет работать **идеально и из коробки**. 
Плеер у всех зрителей в комнате получит один и тот же URL плейлиста. Перемотка будет работать мгновенно у всех, так как сегменты уже нарезаны и лежат на диске сервера. Никаких конфликтов с транскодером на лету не будет.

## План реализации (Пошаговый)

### Этап 1: Подготовка БД и API (Бэкенд)
1. Добавить таблицу `LibraryItems` в `database.dart` и сгенерировать код (`build_runner`).
2. Создать базовые роуты: `/api/library/add`, `/api/library/list`, `/api/library/remove`.
3. Настроить маппинг папок в `docker-compose.yml` (добавить volume `./data/library:/app/library`).

### Этап 2: Сервис загрузки (Download Service)
1. Написать логику скачивания файла. Проще всего использовать API TorrServer: отправляем magnet, получаем ссылку на поток `/stream` и сохраняем этот `Stream` в файл `raw/video.mkv`.
2. Реализовать подсчет скачанных байт для обновления `progress` в БД.

### Этап 3: Сервис транскодирования (Library Transcoding Service)
1. Написать сервис, который мониторит завершенные загрузки.
2. Запуск `ffmpeg` с параметрами для VOD HLS (нарезка по 10 секунд, создание `playlist.m3u8`).
3. Парсинг вывода `ffmpeg` для обновления прогресса транскодирования.
4. Очистка `raw` файла после успеха.
5. Роут для статической отдачи файлов из папки `hls/`.

### Этап 4: Фронтенд-плагин (UI)
1. Создать `custom_plugins/local_library.js`.
2. Добавить пункт меню "Библиотека".
3. Сверстать страницу со списком загрузок (запрашиваем `/api/library/list`).
4. Встроить кнопку "Скачать на сервер" в парсер торрентов.
5. Привязать запуск плеера к готовым файлам.
