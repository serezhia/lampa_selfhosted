# Lampa Self-Hosted

🎬 Полностью самостоятельная версия [Lampa](https://github.com/yumata/lampa-source) — медиацентра с синхронизацией, Telegram-интеграцией и встроенным поиском торрентов.

## 🌟 Особенности

- ✅ **Автономная сборка** — исходники Lampa клонируются из GitHub при сборке Docker.
- ✅ **Telegram Bot** — регистрация, управление устройствами и профилями через бота.
- ✅ **Синхронизация** — закладки, профили, история просмотров (таймлайн).
- ✅ **Sync Player** — совместный просмотр с друзьями в реальном времени через WebSocket.
- ✅ **Встроенный поиск** — интеграция с Jacred (Jackett-совместимый агрегатор) для поиска торрентов.
- ✅ **Транскодинг** — встроенный транскодинг видео и субтитров в HLS через FFmpeg.
- ✅ **Dart Backend** — быстрый и надёжный сервер на Dart Frog с SQLite (Drift).
- ✅ **Простая установка** — интерактивный скрипт `install.sh` с автоматической настройкой HTTPS (Let's Encrypt).

## 📁 Структура проекта

```text
lampa_selfhosted/
├── source/                 # Исходники компонентов
│   ├── web/                # Frontend (патчи для Lampa, кастомные плагины)
│   ├── server/             # Backend (Dart Frog API + WebSocket)
│   ├── nginx/              # Шаблоны конфигурации Nginx
│   └── jacred/             # Шаблоны конфигурации Jacred
├── data/                   # Пользовательские данные (не в git)
│   ├── database/           # SQLite база данных
│   ├── plugins/            # Пользовательские плагины (hot-reload)
│   ├── jacred/             # Данные и конфиги Jacred
│   ├── torrserver/         # Данные TorrServer
│   └── certs/              # SSL сертификаты
├── docker-compose.yml      # Оркестрация контейнеров
└── install.sh              # Скрипт автоматической установки
```

## 🚀 Быстрый старт

Самый простой способ развернуть проект — использовать автоматический скрипт установки. Он сам скачает репозиторий, настроит домены, SSL-сертификаты и запустит контейнеры.

### 1. Подготовка

Вам понадобится:
1. Сервер с установленным Docker и Docker Compose.
2. Доменное имя, направленное на IP вашего сервера.
3. Telegram-бот (создается через [@BotFather](https://t.me/BotFather), нужен только токен).

### 2. Установка

Выполните одну команду в терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/serezhia/lampa_selfhosted/main/install.sh | bash
```

Скрипт задаст несколько вопросов (домен, токен бота, email для SSL) и автоматически всё настроит. По умолчанию проект устанавливается в `/opt/lampa`.

### 3. Использование

1. Откройте вашего Telegram-бота и нажмите `/start` для регистрации.
2. Бот выдаст 6-значный код.
3. Откройте ваш домен в браузере, перейдите в настройки авторизации и введите этот код.

## 🔌 Система плагинов

Проект использует систему плагинов с поддержкой **runtime overlay**. Вы можете добавлять свои плагины или переопределять встроенные без пересборки контейнеров.

1. **Встроенные плагины** (`source/web/custom_plugins/`) — поставляются с проектом (авторизация, синхронизация, транскодинг и т.д.).
2. **Пользовательские плагины** (`data/plugins/`) — ваши личные плагины.

Чтобы добавить свой плагин или переопределить встроенный (создав файл с таким же именем), просто положите его в папку `data/plugins/` и перезапустите frontend:

```bash
docker compose restart lampa-frontend
```

## 🤖 Telegram Bot

Бот используется как единая точка входа и управления аккаунтом.

**Основные команды:**
- `/start` — Регистрация в системе.
- `/add` — Сгенерировать 6-значный код для привязки нового устройства.
- `/devices` — Управление привязанными устройствами (переименование, удаление).
- `/profiles` — Управление профилями (создание, удаление).

**Админские команды** (доступны пользователям из `TELEGRAM_ADMIN_PHONES`):
- `/admin` — Панель администратора (статистика, управление пользователями, рассылки).

## 🏗️ Архитектура сборки Frontend

Мы не храним исходники Lampa в репозитории. Вместо этого:
1. При сборке `lampa-frontend` клонируется оригинальный репозиторий `yumata/lampa-source`.
2. Применяются патчи из `source/web/patches.json` (замена доменов, отключение лишнего функционала).
3. Собирается релизная версия через `gulp`.
4. Результат раздается через Nginx вместе с нашими кастомными плагинами.

Это позволяет легко обновлять ядро Lampa простой пересборкой контейнера:
```bash
docker compose build --no-cache lampa-frontend
docker compose up -d lampa-frontend
```
