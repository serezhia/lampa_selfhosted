# Реализация Storage Sync и Пользовательских Плагинов

В этом обновлении была добавлена поддержка синхронизации пользовательских данных (Storage Sync) и управление личными плагинами через Telegram-бота.

## 1. База данных (Drift)
Схема базы данных была обновлена до версии `8`. Добавлены две новые таблицы:

*   **`StorageData` (v7):** Универсальная таблица для хранения синхронизируемых данных Lampa.
    *   `profileId`: Привязка к профилю пользователя.
    *   `key`: Имя поля (например, `online_view`, `user_clarifys`).
    *   `type`: Тип данных (`array_string`, `object_object`, `object_string`).
    *   `data`: JSON-строка с самими данными.
*   **`UserPlugins` (v8):** Таблица для хранения личных плагинов пользователя.
    *   `userId`: Привязка к пользователю.
    *   `url`: Ссылка на плагин.
    *   `name`: Опциональное имя плагина.
    *   `status`: Статус активности (по умолчанию 1).

*Миграции для обеих таблиц добавлены в `AppDatabase.migration`.*

## 2. Синхронизация данных (Storage Sync)
Lampa использует WebSocket для синхронизации данных в реальном времени и REST API для их получения при загрузке.

*   **WebSocket (`socket_service.dart`):** Добавлен обработчик `_handleStorage` для метода `storage`. Он парсит входящие данные (`id`, `name`, `value`, `remove`, `clean`), определяет тип данных (массив или объект) на основе имени ключа, обновляет JSON в базе данных и рассылает изменения другим подключенным устройствам пользователя.
*   **REST API (`routes/api/storage/data/[key]/[type].dart`):** Создан динамический роут, который отдает сохраненные данные при загрузке Lampa. Если данных нет, он возвращает пустой массив `[]` или объект `{}` в зависимости от типа.

**Поддерживаемые ключи:**
*   `online_view` (array_string) - просмотренные фильмы/сериалы онлайн.
*   `search_history` (array_string) - история поиска.
*   `torrents_view` (array_string) - просмотренные торренты.
*   `user_clarifys` (object_object) - пользовательские уточнения для поиска.
*   `torrents_filter_data` (object_object) - сохраненные фильтры торрентов.
*   `online_last_balanser` (object_string) - последний выбранный балансер.

## 3. Пользовательские плагины
Пользователи теперь могут добавлять свои собственные плагины через Telegram-бота, и они будут автоматически подтягиваться в их Lampa.

*   **Telegram Бот (`telegram_bot.dart`):**
    *   В главное меню добавлена кнопка `🧩 Мои плагины`.
    *   При нажатии открывается список добавленных плагинов.
    *   Каждый плагин можно удалить нажатием на кнопку с его именем (например, `❌ plugin.js`).
    *   Есть кнопка `➕ Добавить плагин`, которая переводит бота в режим ожидания ввода URL плагина.
*   **REST API (`routes/api/plugins/all.dart`):** Эндпоинт возвращает список плагинов для текущего пользователя (определяется по токену устройства). Формат ответа соответствует тому, что ожидает Lampa (`{"secuses": true, "plugins": [...]}`).

## 4. Статические эндпоинты
Добавлены заглушки для статических файлов, которые запрашивает Lampa:
*   `routes/plugins_black_list.json.dart` — возвращает пустой массив `[]`.
*   `routes/personal.lampa.dart` — возвращает `{"status": "ok"}`, чтобы Lampa активировала "персональные" функции.

## 5. Middleware
Обновлен `routes/api/_middleware.dart`:
*   Добавлены исключения для публичных эндпоинтов (`/plugins/all`).
*   Для `/plugins/all` добавлена логика опциональной авторизации: если токен передан, middleware пытается найти пользователя, но не блокирует запрос (не возвращает 401), если токена нет или он невалиден. Это позволяет Lampa загружаться даже без авторизации, просто с пустым списком плагинов.
